# Nest Egg

Household net worth and retirement planner from the Core lab. Fake data only. A projection, not financial advice.

```bash
npm install
npm run check
npm run dev
```

Open http://localhost:3000 and sign in as `a@example.test` / `nest-a`.

`data/practice.json` is created on first run and is gitignored. Tests use a separate in-memory database.
