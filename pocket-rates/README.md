# Pocket Rates

A currency converter for your phone, built with Expo.

```bash
npm install
npm run check
npx expo start
```

Scan the QR code with Expo Go. The phone and the computer need the same Wi-Fi. On an iPhone, since SDK 57, Expo Go and `npx expo login` must use the same free Expo account. If Expo Go cannot connect, open the web view from the dev server.

Sharing without an app store is described in SHARE.md. Do not start a cloud build until you approve it.
